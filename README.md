# -Fat-Tree-Network-Topology-Generation-and-Analysis-


Fat-Tree Network Topology GeneratorOverviewThis repository contains a Python-based generator and analyzer for Fat-Tree data center network topologies, as described by Al-Fares et al. (2008). The project is designed to construct a three-tier hierarchical network structure (Core, Aggregation, Edge) and includes functionality to model link failures and analyze network metrics.ApproachThe topology generator is implemented using Python and the networkx library, which provides robust data structures for graphs and built-in algorithms for pathfinding and network analysis.The current initial code constructs the structural foundation of the $k$-ary Fat-Tree:Core Layer: $(k/2)^2$ switches.Aggregation & Edge Layers: $k$ pods, each containing $k/2$ aggregation switches and $k/2$ edge switches.Hosts: $(k/2)^2$ hosts per pod.PrerequisitesTo run this code, you need Python installed along with the networkx library.Install the required dependencies:pip install networkx matplotlib
UsageRun the generator via the command line. You can specify the port count ($k$) and the failure rate.python fat_tree.py -k 4 --failure-rate 0.01
Parameters:-k: The number of ports per switch (must be an even number). Default is 4.--failure-rate: The percentage of link failures to simulate (e.g., 0.01 for 1%).
